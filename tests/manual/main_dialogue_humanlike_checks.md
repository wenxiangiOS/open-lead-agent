# MAIN_DIALOGUE 拟人化检查项（重排后）

用途：验证 `MAIN_DIALOGUE` 重排后，对话逻辑不变、拟人化不下降。

## 检查项（5条）

1. 承接自然性
- 观察点：回复开头是否先承接用户上一句，再推进主线。
- 通过标准：至少 80% 轮次出现自然承接，不出现机械开场模板复读。

2. 转场顺滑度
- 观察点：从一个字段切到另一个字段时是否有过渡语。
- 通过标准：不出现“硬切式盘问”；字段切换时有简短过渡说明。

3. 追问节奏控制
- 观察点：同一字段第2次追问是否换角度并给简短理由，第3次是否跳过。
- 通过标准：不连续三轮盯同一字段；第2次追问语气明显不同于第1次。

4. 情绪与认可克制
- 观察点：用户表达情绪时是否先回应情绪；认可是否克制不过度吹捧。
- 通过标准：有情绪先回应；无“条件真好/太优秀了/很抢手”模板化夸赞堆叠。

5. 答疑优先一致性
- 观察点：用户提问/顾虑时是否先完整答疑，再回主线收集。
- 通过标准：答疑轮不插入资料盘问；答疑后再自然回到收集。
